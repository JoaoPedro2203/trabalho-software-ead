# 📋 Task Manager Agile

Projeto de gerenciamento de tarefas desenvolvido com:

- HTML
- CSS
- JavaScript
- Jest
- Git/GitHub

---

# ✅ Objetivo do Projeto

O sistema permite:

- Adicionar tarefas
- Remover tarefas
- Salvar tarefas automaticamente
- Persistir dados usando LocalStorage
- Executar testes automatizados

# 🚀 PASSO A PASSO COMPLETO

# 1️⃣ Instalar o Node.js

Baixe:
https://nodejs.org

Depois verifique:

```bash
node -v
npm -v
```

---

# 2️⃣ Abrir o Projeto

Abra a pasta no VS Code.

---

# 3️⃣ Instalar Dependências

No terminal:

```bash
npm install
```

Isso instala:
- Jest
- Dependências do projeto

---

# 4️⃣ Executar Testes

```bash
npm test
```

---

# 5️⃣ Rodar o Projeto

Abra:

```bash
src/index.html
```

no navegador.
